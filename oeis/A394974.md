**NAME**

a(n) = number of pairs (c,d) of integers with 1 <= c <= n-1 and 1 <= d <= n-1 such that n*c + d divides (n-1)*d.

**COMMENTS** (each line one full sentence; no carriage returns mid-sentence)
```
Equivalently, a(n) is the number of pairs (c,d) such that n*c+d divides c*n^k+d for every k >= 1.
This matches the name because c*n^k+d - n^(k-1)*(n*c+d) = d*(1-n^(k-1)), so n*c+d divides c*n^k+d iff it divides d*(n^(k-1)-1); since n-1 divides every n^(k-1)-1, this holds for all k iff n*c+d divides (n-1)*d.
a(n) = 0 if and only if n is prime.
Interpretation in base n: writing n*c+d as the two-digit string cd with nonzero digits c, d, the integers c*n^k+d are obtained by inserting k-1 zeros between the digits, so a(n) counts the two-digit base-n numbers whose zero-insertions remain divisible by them.
The quotients (c*n^k+d)/(n*c+d) equal 1 + e*(n^(k-1)-1)/(n-1) for a constant e; in base 10 the quotient families are A059482, A067275 and A093142.
```

**FORMULA** (single line)
```
a(n) = Sum_{k=1..n-2} floor((n-1)/L_k), where L_k = n*k/(gcd(k+1, n) * gcd(k, n-1)).
```

**EXAMPLE**
```
n=10: the seeds are 15, 18, 45 (digit pairs (1,5),(1,8),(4,5)), so a(10)=3.
n=6:  the seeds are 10 and 15 (digit pairs (1,4),(2,3)), so a(6)=2.
For prime n (e.g. n = 5, 7, 11) there are no seeds, so a(n)=0.
```
